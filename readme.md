# 眨眼翻頁

給閱讀 App（微信讀書等）用的眨眼翻頁工具：前鏡頭看臉，不用碰手機。免 root，靠無障礙 `dispatchGesture` 點螢幕；辨識用 MediaPipe FaceLandmarker（眨眼 blendshape）＋HandLandmarker（拳頭，離線）。

## 功能一覽

| 想做什麼 | 在哪操作 | 會發生什麼 |
|---|---|---|
| 下一頁 | 閉眼維持約 0.6 秒（自然眨眼不算） | 點一下螢幕右中 |
| 上一頁 | 閉眼維持時拳頭在鏡頭前 | 點一下螢幕左中 |
| 開始/暫停翻頁 | 閱讀頁點懸浮球（▶→❚❚） | 開/關前鏡頭；球 2 秒內自癒，不會消失；自家設定頁點球無反應 |
| 看鏡頭有沒有看到臉 | 懸浮預覽窗 | 跟相機同開同關；閉眼計數中畫綠圈，眨眼畫紅圈（下頁），眨眼+拳頭畫黃圈（上頁）；本體拖移，右下角拖縮放；大小共用記住，位置直屏/橫屏分開記 |
| 喬角度 | 設定頁「眨眼測試開/關」 | 30 秒小窗預覽＋辨識狀態，眨眼會 Toast（不翻頁） |
| 調連翻間隔 | 設定頁「翻頁冷卻」1~30 秒 | 預設 3 秒；冷卻內手勢丟掉 |
| 人走開自動停 | 設定頁「閒置自動停」1~30 分鐘 | 預設 5 分鐘沒翻頁：關相機＋停球＋關小窗；自己用手滑頁也算活著，會重數 |
| 只在特定 App 翻 | 設定頁「選擇可翻頁的 App」 | 預設只勾微信讀書；全不勾＝全部允許 |
| 調懸浮球深淺 | 設定頁「懸浮球透明度」10~100% | 即時生效 |
| 調預覽窗大小深淺 | 設定頁「預覽窗大小」80-400dp／「透明度」10-100% | 預設 200x150；拖縮放放開自動記住 |
| 回設定頁改東西 | 長按懸浮球 600ms | 跳回設定頁；回設定頁自動停本次會話 |
| 橫屏也在翻 | 把手機轉橫 | 點位重算，預覽窗轉正跟著轉 |

## 翻頁規則（三條）

1. 閉眼維持約 0.6 秒（連續 6 幀）：下頁；自然眨眼（約 0.1-0.2 秒）忽略不翻。
2. 閉眼達標那一幀拳頭同時在鏡頭前：上頁（先把拳頭舉著再閉眼最穩）。
3. 睜眼才重上膛：閉著不連翻，冷卻內眨眼丟掉。

## 安全停止（不用記，自動的）

* 相機只在 AND 才開：無障礙開＋翻頁服務開＋球點火＋前景在白名單內。
* 自家設定頁／非白名單 App／桌面：關鏡頭＋關預覽窗＋藏球（球只出現在自家和白名單）。
* 手勢被系統拒收（金融／遊戲頁）：自動停，免得空轉。

## 開始使用（3 步）

1. 開 App →「1. 開無障礙權限」→ 啟用 眨眼翻頁；「2. 開懸浮窗權限」→ 允許；「3. 開相機權限」→ 允許。
2. 按「眨眼測試開/關」看小窗，閉眼有反應才繼續（喬角度用）；設冷卻、選白名單 App → 按「開啟翻頁服務」（只掛球，不開鏡頭）。
3. 進閱讀 App 內文頁 → 點球變 ❚❚ 開鏡頭＋預覽窗；再點（▶）即停。

## 常見問題（看症狀）

* **閉眼不翻**：臉有沒有進小窗；維持不夠久（要約 0.6 秒，自然眨眼不算）；閉著沒睜（睜眼重上膛）；冷卻還沒過；白名單有沒有勾該 App。
* **小窗人像是歪的／鏡像反了／紅圈套偏**：報方向（豎屏／橫屏充電口左右）＋現象，轉正、鏡像、紅圈座標都按機型調（realme GT Neo2 已調正）。
* **球 ❚❚ 但不翻**：剛切進書頁 3 秒內是校準期，等一下；球不見的話 2 秒看門狗會自己長回來。
* **每次 Run 都要重開無障礙**：完整解除安裝會清系統綁定，屬 Android 設計。改用 `adb install -r` 覆蓋；Apply Changes 不會重啟跑著的無障礙服務（小窗仍是舊碼）——以「比拳頭有紅圈」為準確認新碼在跑。

## 開發者

* 環境：Android Studio＋ SDK API 34；手機 Android 8+（`minSdk 26`）。
* 檔案：`MainActivity.kt`（設定頁）／`PageTurnService.kt`（門控／翻頁輸出／懸浮球／相機生命週期／預覽窗／2 秒看門狗）／`EyeTracker.kt`（Camera2 前鏡頭＋Face 眨眼＋拳頭幾何＋預覽轉正＋臉心座標回調）／`res/xml/accessibility_service_config.xml`。
* 自檢：`EyeTracker.demo()` 驗眨眼邊緣邏輯（自然眨眼忽略／6 幀觸發／閉著不連翻），無需相機。
